THE ALGORITHM, UNPACKED

A shared sequence, one decision at a time.

A subsequence keeps the original order but can skip bases. Unlike a substring, it does not need to be continuous.

01

Start with empty prefixes

Create a table with one extra row and column. Their values are zero: an empty sequence has no shared bases.

02

Compare each pair of bases

If the bases match, extend the answer diagonally by one. If they differ, keep the larger answer from above or to the left.

03

Retrace the decisions

Walk back from the final cell. Diagonal matches form the LCS. Ties move upward, selecting one deterministic optimal answer.

Similarity is not biological identity

The score is 2 × LCS length ÷ (length A + length B). It measures ordered overlap, not mutations, evolutionary distance, or a clinically meaningful alignment. Different optimal subsequences may have the same length.
